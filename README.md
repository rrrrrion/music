# Looply を iPhone のホーム画面に追加する（Webアプリ版）

この版は **iPhone にアイコンを追加して、Safari のタブなしで起動できる PWA** です。無料、Mac不要、Apple Developer登録不要。App Storeに配信する「ネイティブiOSアプリ」ではありません。

## GitHub Pages への配置

今あるリポジトリの `main` ブランチ、ルート (`/(root)`) に以下を置いてください。

```
index.html
manifest.webmanifest
sw.js
icons/
  icon-192.png
  icon-512.png
  apple-touch-icon.png
```

ZIPを解凍して中身をそのままリポジトリのルートにアップロードしてください。既存の `index.html` は最新版で上書きします。GitHub Pages が有効なら以前と同じサイトURLで利用できます。

## iPhoneへの追加

1. iPhoneのSafariでGitHub PagesのURLを開く。
2. Safariの共有メニューから「ホーム画面に追加」を選択。
3. 「Webアプリとして開く」をオンにして「追加」。
4. ホーム画面のLooplyアイコンから起動。

初回起動やアプリファイル更新には通信が必要です。その後はアプリ画面の一部をオフラインで開けます。曲や動画は端末のブラウザ側に保存されます。

**大切:** iOSのホーム画面WebアプリとSafariは保存領域が別になる場合があります。**Safari版にすでにファイルを保存している場合は、ホーム画面に追加する前にSafariのLooplyで「ZIPバックアップ」を作成し、ホーム画面版のLooplyで「ZIPから復元」してください。** 動画・音楽が多い場合、端末の空き容量と保存容量制限に注意してください。

## 制限

- **バックグラウンド音声再生は保証されません。** 1曲リピートはしやすくなっていますが、iOSがWebアプリを停止すると次の曲に進まない場合があります。
- MP4映像を他アプリの上で表示する機能（ピクチャ・イン・ピクチャ）はこの版には実装していません。
- メディアファイルはGitHubにアップロードされません。Webアプリのブラウザ保存領域は消える場合があります。定期的にZIPバックアップを作成し別の場所にも保管してください。
- **通常のiOSアプリ**として安定したバックグラウンド再生を重視するなら、Mac + Xcode + ネイティブのAVPlayer / AVAudioSessionを使う別実装が必要です。

# Looply 音楽・動画プレイヤー

MP3などの音声ファイルとMP4などの動画ファイルを追加し、プレイリストで連続・リピート再生できるWebサイトです。追加したファイルは**外部サーバーにはアップロードされません**。

## 使い方

1. `index.html` をChrome・Edgeなどのブラウザで開きます。
2. 「ファイルを追加」を押すか、音楽・動画をドラッグ＆ドロップします。
3. 一覧の各曲・動画にある鉛筆アイコンを押すと、**表示名とメモ**を編集・保存できます（例：表示名「夜の作業用」、メモ「落ち着いた曲」）。元の音楽・動画ファイルは変更されません。プレイリスト内の検索は名前とメモの両方を探します。
4. 一覧のファイルをクリックすると再生されます。動画を選ぶと、上に映像プレイヤーが表示されます。動画の操作パネルから全画面表示もできます。
5. リピートボタンで「全曲リピート → 1曲リピート → リピートなし」を切り替えられます。音声・動画混在のプレイリストでも利用できます。
6. 「新しいプレイリスト」で別のプレイリストを作成できます。
7. 保存したデータを守るには、左側（スマホではプレイリストの下）の「保存とバックアップ」から「保存を保護する」を押してください。ブラウザによっては保護が許可されない場合があります。
8. 「ZIPバックアップ」で**音声・動画のファイルそのもの、曲名、メモ、プレイリスト**をまとめて端末にダウンロードできます。復元するときは「ZIPから復元」を選んでください。現在のデータは消さずに追加します。

### 対応形式

- 音声: MP3 / WAV / M4A / OGG / AAC など
- 動画: MP4 / WebM / MOV / M4V など

**実際に再生できる形式やコーデックはブラウザによって異なります。** 特にMP4はH.264/AACなど一般的なコーデックを推奨します。

## スマホでバックグラウンド再生（追加機能）

**操作手順**

1. スマホのSafari（iPhone）またはChrome（Android）でGitHub Pagesのサイトを開いて、MP3/M4Aなどの音楽を**ページ上で再生開始**します。
2. 再生したままホーム画面に戻る、別のアプリへ移動する、または画面をロックします。対応端末では音声の再生が続きます。
3. 対応ブラウザではロック画面・通知画面・イヤホンのボタンから、再生・一時停止・曲送りなどを操作できます。Media Session APIが使えない端末ではこれらの操作は表示されない可能性があります。
4. **MP4の音声だけを聴く場合**は、ページ内の「動画の音声だけ：ON」にしてから再生します。OFFに戻すと動画映像が表示されます。この設定は保存されます。
5. 1曲リピートではHTMLメディア標準のループを使用するため、JSが停止しやすいバックグラウンド環境でも繰り返しやすい構成になっています。

**注意**：Webサイトはネイティブの音楽アプリとは異なるため、iPhone/AndroidのOSやブラウザ、バッテリー制限などによって、アプリ切り替え後に音声が止まることがあります。バックグラウンドでの次曲への自動切り替えも保証されません。特に動画の音声のみ再生は、ブラウザがMP4音声トラックの再生に対応する場合に限られます。再生に失敗したら、音声ファイル（MP3/M4A）を使ってください。Safari/Chromeのタブを完全に閉じず、最初はページで再生ボタンを押してください。アプリ内ブラウザでは動かない場合があります。

## GitHub Pagesで既存サイトを更新

1. GitHubの該当リポジトリを開いて、ルートにある既存の `index.html` をクリックします。
2. ファイル右上の鉛筆アイコン（Edit this file）をクリックし、**既存のコードを全部削除して**この `index.html` の内容を全部貼り付けます。
3. **Commit changes** を押して保存します。
4. **Settings → Pages** が **Deploy from a branch → main → /(root)** に設定されていることを確認します。
5. **Actions** の Pages デプロイが成功すれば、元のURLから新版を開けます。更新直後は再読み込みしてください。

まだサイトを作っていない場合も、新しいリポジトリのルートに `index.html` を配置すれば公開できます。

## 主な機能と注意

- 音声・動画を同一プレイリストに登録して、前後送り・シャッフル・リピート
- 再生／一時停止／シーク／音量／再生速度変更
- スマホ向けバックグラウンド音声再生の補助、Media Session APIによるロック画面/イヤホンの再生操作（対応ブラウザのみ）
- MP4を映像なしで音声再生する切り替えと設定保存
- 動画再生画面と動画の全画面表示（ブラウザの動画操作パネル）
- プレイリストの作成・名前変更・削除、曲・動画それぞれの表示名とメモの編集・検索、ファイルの並べ替えと削除
- IndexedDBにローカル保存。**旧版と同じ保存領域を使うため同じURLのまま更新すれば既存のリストを維持できます。**
- スマホ・PC対応。ファイルは端末とブラウザごとに保存され、同期・共有されません。
- 大きな動画はブラウザの保存容量の上限に達することがあります。サイトデータを削除すると保存したファイルは消えます。
- IndexedDBはサイトを閉じた後もデータを保持しますが、「永遠に消えない」と保証できる保存場所ではありません。**ブラウザのデータ削除、シークレットモード、別ブラウザ、端末の故障**には要注意です。ZIPを別のフォルダや外部ストレージにも保存してください。
- ZIPバックアップは約4GBまで（ZIP32形式）。大容量の動画が多い場合はこの形式の一括バックアップはできません。
- 既存のサイトURLと同じURLで更新してください。**別のURLや別のブラウザでは、元のローカル保存データは自動で表示されません。**
- GitHub Pagesの**サイトそのものは一般公開される場合があります**が、このサイトで追加する曲・動画は外部サーバーへ送信されず、他人のブラウザには表示されません。
